# Contributing

Keep one installable skill. Put reusable design decisions in concise references and executable behavior in the workbench/CLI. Add a meaningful check for any change to diffs, conditional commands, rollback or light statistics.

Do not commit saves, raw game scans, personal coordinates, third-party tutorial frames, secrets or generated NBT. An example should be newly authored, anonymous and runnable or clearly labeled as a decision study.

For Minecraft version changes, record the exact game build, data version, data pack format, block state differences and bridge capabilities. State whether the result was tested in-game or only by a compatibility check. Never claim a light level from a shader preview.
