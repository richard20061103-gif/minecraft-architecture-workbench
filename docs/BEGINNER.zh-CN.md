# Minecraft Architecture Workbench 新手教程

本教程以 Windows、Codex 和 Minecraft Java 版为例。你可以先不打开游戏，体验让 AI 设计和生成网页 3D 预览；如果要读取地形或在游戏里建造，还需要配置游戏桥接。

目前的 v1.0.0-rc.1 是候选版：Windows、macOS、Linux 的自动检查通过，但新安装流程连接真实游戏的完整过程还未重新实测。Java 1.21.8 是项目此前的实机基础，其他 1.21.x 版本和 NeoForge 暂为实验性。

## 1. 准备和下载

准备好能运行本地命令、加载技能的 Codex，及其账号。AI 服务可能收费；Minecraft 和游戏启动器需要另外准备。安装和桥接下载需要联网。

打开 [Release 页面](https://github.com/richard20061103-gif/minecraft-architecture-workbench/releases/tag/v1.0.0-rc.1)，在 Assets 中下载 `minecraft-architecture-workbench-v1.0.0-rc.1.zip`。这是完整包；`skill` 包适合熟悉手动配置的人。

右键压缩包解压到一个准备长期保留的文件夹，例如 `D:\MinecraftWorkbench`。以后启动工作台仍需要这个文件夹。

## 2. 安装技能和示例

打开解压后的文件夹，双击 `install.cmd`。

1. 若提示需要 Node.js，选择是否下载官方的用户目录版运行环境，输入 `Y` 同意。下载和依赖安装需要一点时间。
2. 出现技能目录提示时，如果使用 Codex，直接按回车选择默认目录；其他助手需要填写其技能目录的完整路径。
3. 提示“开始安装？”时输入 `Y`。如果已有不同版本，向导会询问是否备份并更新，请根据提示决定。
4. 出现“配置 Minecraft 游戏桥接？”时，想先看预览就输入 `N`。安装完成后按提示关闭窗口。
5. 重启或重新加载 Codex，再开始新对话。安装文件成功不等于当前对话已经加载技能。

双击同一文件夹里的 `workbench.cmd`，浏览器会打开示例工作台。尝试旋转模型；运行窗口需要保持打开，关闭后本机网页也会停止。

## 3. 让 AI 设计第一个建筑

在新的 Codex 对话中输入：

```text
使用 $minecraft-architecture，设计一座现代日式小车站。
场地大约 40 × 30 格，需要候车区、站台、楼梯和照明。
先制作能在浏览器旋转的 3D 模型，并展示室内和剖面；暂时不要修改游戏存档。
```

也可以把参考图、想要的风格和必须保留的部分告诉 AI。工作台提供工具和工作流程，AI 负责理解需求、设计和使用工具；最终效果取决于模型能力和你的反馈。只有概念描述时，AI 不能声称已经看过实际地形。

网页模型是预览，不会自动放进游戏。对外观、室内、交通或照明不满意时，把问题集中告诉 AI，请它修改并提供新版预览。

## 4. 连接自己的 Minecraft（需要进游戏时）

1. 准备 Minecraft Java 版和已有的 Fabric 或 NeoForge 游戏实例。建议先用独立测试世界；普通原版或 Forge 实例不能直接使用所需模组。
2. 再次运行 `install.cmd`，在“配置 Minecraft 游戏桥接？”处输入 `Y`。按提示填写**游戏实例目录**，通常里面有 `mods` 和 `config` 文件夹；不要选择 `saves` 里的世界文件夹。
3. 向导会尝试查找并安装与该实例兼容的 MCPFabric 及所需依赖，准备 Codex 连接。若选择默认只读，AI 可以在支持时查看，不能施工。写入和游戏命令能力需另行选择并验证；当前候选版的写入授权变更尚未完成实机测试。
4. 重启所选 Minecraft 实例，进入要使用的世界，并重启或重新加载 Codex 的连接配置。安装成功不代表连接成功。
5. 在 Codex 中要求检查连接、当前世界和权限。也可以在项目文件夹的终端执行：

```text
workbench.cmd bridge check --instance "你的游戏实例目录"
```

如果没有兼容模组或检查失败，可以继续使用设计与预览功能；查看 [详细安装与排错](INSTALL.zh-CN.md)。

## 5. 勘探与施工

连接正常后，明确说明世界、位置、允许修改范围以及要保护的建筑、箱子、红石和地形。第一次建议使用测试世界，先让 AI 勘探和预览：

```text
使用 $minecraft-architecture 检查当前世界和桥接状态。
勘探我面前适合建设的区域，记录范围和地形，保护现有道路与红石。
设计车站并生成 3D 预览，暂不施工。
```

确定要施工时，明确授权目标世界和范围，并要求先做可恢复备份、核对受影响方块和桥接写入能力。不要把“已生成预览”或“已安装桥接”当作“已成功施工”。网页夜景也不能代替游戏内实际测光。

## 常见问题

- **找不到技能**：确认安装完成后重启了 Codex，技能目录下能找到 `minecraft-architecture/SKILL.md`；再开新对话。
- **网页打不开**：保持 `workbench.cmd` 窗口运行，使用终端实际输出的网址。重新启动后端口可能变化。
- **不能连接游戏**：确认选择的是正确实例、游戏已重启并进入世界，再检查桥接状态和权限；详见 [安装与排错](INSTALL.zh-CN.md)。
- **AI 不能操作文件或运行命令**：需要具备本地工具权限的 agent；普通聊天界面不一定能完成安装或施工。

不要把存档、令牌或本地 `.workbench` 记录上传到公开仓库。
